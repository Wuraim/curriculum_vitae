\subsection{\href{https://github.com/Wuraim/gregobot-oss}{Gregobot}}
\subtext{Virtual Workout Coach for Friends --- Self-Hosted Rust Bot \& Admin API}

\begin{zitemize}
    \item Personal Telegram coach for friends and me (\textasciitilde200 commits): bot and authenticated REST admin API in one async Rust service (Tokio, Axum, Teloxide).
    \item Persisted domain data with SQLite/SQLx migrations; background schedulers for reminders and AI workflows.
    \item Optional Gemini layer: embeddings and top-K retrieval over domain data/tools, plus tool calling, in the same process.
    \item Self-hosted via Docker with API-key auth; deliberate MIT/Apache-2.0 public release.
    \item Technologies: Rust, Tokio, Axum, Teloxide, SQLx, SQLite, Docker, Gemini.
\end{zitemize}
